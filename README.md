# Les Coteaux en Vue

Site web des Coteaux en Vue : deux logements en rez-de-jardin avec piscine à Aureville, près de Toulouse.

## Contenu du dossier

| Fichier | Rôle |
|---|---|
| `index.html` | Le site |
| `content.js` | Tous les textes et les noms des photos du site |
| `images/` | Les photos |
| `admin.html` | Le panneau d'administration (à ouvrir sur l'ordinateur avec Chrome ou Edge) |

## Modifier le site

1. Ouvrir `admin.html` depuis l'ordinateur avec Google Chrome ou Microsoft Edge.
2. Modifier les textes et les photos, puis cliquer sur **Enregistrer**.
3. Envoyer les changements sur GitHub (`content.js` et les nouvelles photos du dossier `images`).
