Les Coteaux en Vue

Pour modifier ton site depuis n'importe où (ordinateur, téléphone, tablette), le panneau a besoin d'une clé GitHub. Tu ne la crées qu'une seule fois par appareil.

Comment créer ma clé (2 minutes)
  1. Ouvre cette page GitHub (elle est en anglais, tu peux la traduire avec ton navigateur).
  2. Token name (nom) : écris Panneau Coteaux en Vue.
  3. Expiration : choisis la durée la plus longue proposée.
  4. Repository access (accès) : choisis Only select repositories (seulement certains dépôts), puis sélectionne coteaux-en-vue.
  5. Permissions : clique sur Add permissions (ajouter), choisis Contents, puis règle-le sur Read and write (lecture et écriture).
  6. Clique sur Generate token (générer), puis copie la clé qui commence par github_pat_.
  7. Colle-la ci-dessous. Ne la donne à personne d'autre.
